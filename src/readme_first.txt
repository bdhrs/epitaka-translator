ePitaka Proofreading — read this first

One doc = one book. A long book is split into parts: _1, _2 and so on. Each paragraph: a Pāli line (in the {language} script), a blank line, its {language} translation. Where an automatic review found a problem, the review remarks follow after a blank line. Two blank lines end the paragraph. The review remarks are hints from an automatic review. They can be wrong. Check them against the Pāli.

How to work — five points
1. Sign in to your Google account, or you can only read. Set the pencil menu (top right) to "Suggesting".
2. To fix a mistake, type the fix straight into the translation. It shows as a suggestion. Nothing else is needed. Do not retype whole paragraphs. Never change a Pāli line. Keep the layout.
3. If the same mistake must be fixed in every place, add a comment on your fix with the word EVERYWHERE. You can add a few plain words, for example: "EVERYWHERE, but not when it means a person".
4. If the Pāli meaning is wrong, write a comment in {language} or English and say what the Pāli means. If you are not sure, start the comment with the word QUESTION.
5. When you finish a doc, comment DONE on its first line.

Spelling and grammar fixes need no comment, unless they must be fixed everywhere (point 3).
